# Professional Student Portfolio Template

A polished static portfolio template for a 4th-year student preparing for internships, entry-level roles, and capstone presentations.

## Files

- `index.html` - Page structure and editable portfolio content.
- `styles.css` - Responsive styling, layout, and theme variables.
- `assets/portfolio-hero.png` - Generated professional hero image.

## Customize

Update the placeholder name, course/program, project cards, school timeline, links, and email address in `index.html`. Adjust colors in `styles.css` under the `:root` variables.

Open `index.html` in a browser to preview the site.
