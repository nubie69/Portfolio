# Professional Student Portfolio Template

A polished static portfolio template for a 4th-year student preparing for internships, entry-level roles, and capstone presentations.

## Files

- `index.html` - Page structure and editable portfolio content.
- `projects.html` - Full project collection with category filters.
- `certificates.html` - Full certificate collection with category filters and search.
- `portfolio.js` - Shared filtering and expanded image previews.
- `alagad.html`, `zarvival.html`, `bottle-converter.html`, `cloudbrew.html`, `robotic-arm.html` - Project details and additional screenshots.
- `styles.css` - Responsive styling, layout, and theme variables.
- `assets/portfolio-hero.png` - Generated professional hero image.
- `assets/resume/Zach-Gelacio-Resume.pdf` - Add your resume PDF here so the Resume links can download it.

## Customize

Update the placeholder name, course/program, project cards, school timeline, links, and email address in `index.html`. Adjust colors in `styles.css` under the `:root` variables.

To make your resume downloadable, save your PDF as `Zach-Gelacio-Resume.pdf` inside `assets/resume/`. Anyone who opens the portfolio can use the Resume links to download it.

Open `index.html` in a browser to preview the site.

Keep 3-6 selected project cards and 4-6 selected certificate cards in the homepage sections. Add the full collection to the separate pages. Each card's `data-category` must match an option in that page's category menu. When updating a featured item, update its card on both pages.
